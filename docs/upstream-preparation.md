# Upstream baseline preparation

The detached source in `build/ms56-upstream` is original Lera-Romero `networks2020` commit `cabc56ad9cdb22bed81a8a31f1671d40152055e6`. Build preparation uses its embedded goc library and its original `BP-CUTS` experiment. `patches/upstream-0001-single-thread.patch` adds CPLEX `Threads=1` immediately after defaults are reset. It changes no routing or pricing logic. Hash this patch and the binary in every derived manifest.

The actual build succeeded on reserved grvingt-16 in OAR job 7012687 with CPLEX Studio 12.10 and the Guix `boost` module. `scripts/build_upstream_g5k.sh SOURCE_ROOT BUILD_DIR` reproduces configuration/build on an owned compute node. Source acquisition is `git worktree add --detach build/ms56-upstream cabc56ad9cdb22bed81a8a31f1671d40152055e6` from a repository containing the pinned object, followed, from the experiment repository root, by `git -C build/ms56-upstream apply "$PWD/patches/upstream-0001-single-thread.patch"`. Transfer that source tree without its worktree `.git` pointer to the remote source root. Keep the original commit and patch hash in the build record.

`scripts/upstream_probe_worker.py` feeds the native executable 3 JSON documents on stdin: BP-CUTS parameters, the original upstream instance, and an empty solutions object. It does not supply a reference incumbent. It records native input, experiment and binary hashes. The original customer IDs are unchanged. Native start depot 0 and duplicated end depot n+1 are removed from exported routes, after explicit range checks. The original instance is retained byte-for-byte. No cost or travel-time conversion is guessed.

`scripts/upstream_smoke_g5k.sh` runs a 2 s native C101_25 development smoke with fixed single-core affinity and an external 20 s process-group timeout, followed by a 2 s kill grace. The native limit starts after preprocessing, so this is expressly a smoke test rather than a process-launch-budget performance cell. The final-only adapter cannot recover incumbent production timestamps. Its witness is labeled final-only and receives no anytime or proof credit. An initial development attempt without explicit affinity is retained separately and excluded from matched comparisons.

`scripts/validate_upstream_smoke.py` checks the final witness against the corresponding MAMUT n25 fixture using the pinned v0.11 checker, omitting the native declared cost from the checker input. It retains native-minus-checked cost discrepancies. Validation has no recorded timing. The original n100 fixture arrays align visibly with the MAMUT materialization for customer IDs, service times and time windows, but complete edge-function equivalence remains a launch gate. This smoke alone cannot establish cross-adapter benchmark comparability.

The original main program and BCP retain their original timing and termination control flow. They lack process-launch events, safe incremental global-bound events and a closure census. A native Optimum string is unverified and earns no proof credit here. Before pilot use, instrument upstream comparably, enforce one common outer deadline through preprocessing/search, verify effective CPLEX settings, and establish complete representation equivalence against frozen input hashes. Do not transplant Kayros correctness adaptations without recording a separate necessary-fix patch series.

## Development observations

The fixed-affinity 2 s native C101_25 and C101_50 runs both produced checker-valid complete witnesses. The v0.11 costs were 24,709.177157546477 and 49,242.92185601275. Native-minus-checked differences were approximately -3.64e-12 and -7.28e-12. These are development observations without proof credit or performance interpretation. Raw records remain in ignored `outputs/ms56/upstream-*` directories.

An independent IGP integration audit compared each materialized ATF knot and segment midpoint against the original distance, speed-zone and cluster-speed records for these 2 fixtures. Demands, service times, time windows, capacities, horizons and coordinates agree exactly after removing the duplicated end depot. The maximum finite arrival-time discrepancy was approximately 3.64e-12 over 11,810 samples for n25 and 46,334 for n50. The materialized ATFs additionally contain 650 and 2,550 sampled departures whose arrivals lie beyond the native speed horizon. The native integrator reports those arrivals as unavailable, whereas MAMUT extends the final speed zone. The common TDVRPTW depot-arrival horizon excludes these late arrivals. Preserve this domain distinction in the full equivalence audit. This evidence supports the intended customer/time-scale mapping and identifies the late-domain difference, while leaving all-56 equivalence and floating-point pricing behavior for the pilot gate.
